# 🎓 Alumni Networking Protocol

A secure and user-friendly Alumni Networking Protocol web application that connects alumni, students, and administrators through a centralized platform. The system enables networking, mentorship, job opportunities, event management, and communication between alumni and students.

---

## 📌 Project Description

The Alumni Networking Protocol is designed to strengthen the relationship between educational institutions, alumni, and students. It provides a platform where alumni can share career opportunities, mentor students, participate in events, and stay connected with their institution.

---

## ✨ Features

- 🔐 Secure Login & Registration
- 👨‍🎓 Alumni Dashboard

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/dhivyashreek12/Alumni-Networking-Protocol.git
```

### Move into Project Folder

```bash
cd Alumni-Networking-Protocol
```

### Install Dependencies

```bash
npm install
```

### Start Server

```bash
node server.js
```

Open browser:

```
http://localhost:3000
```
